# 红楼梦人物关系知识图谱

本项目目前只有一个页面文件 [`index.html`](./index.html)。要查看或编辑最新版本的代码，可以使用以下任一方式：

1. **在浏览器中预览**
   - 直接双击或拖拽 `index.html` 到浏览器窗口即可打开页面。
   - 如果在命令行中，执行 `xdg-open index.html`（Linux）或 `open index.html`（macOS）来启动默认浏览器。

2. **在编辑器中查看代码**
   - 使用 VS Code、WebStorm 等编辑器打开仓库根目录，再打开 `index.html` 即可查看完整源码。
   - 若使用命令行，可运行 `git show HEAD:index.html` 查看当前版本内容。

3. **通过静态服务器访问（可选）**
   - 在项目根目录执行 `npx serve .` 或使用任意静态服务器，然后在浏览器访问提示的地址以获得本地预览。

如需进一步帮助，请告知你使用的操作系统或开发环境，我们可以提供更具体的操作步骤。
